Built a personal assistant app with FastAPI and React.js which allows patients to review and discuss their recorded doctor visits with an AI-powered chatbot. Integrated OpenAI's Whisper API for audio transcription and GPT-4 for multimodal responses to patient queries. Used Python and JavaScript to connect frontend and backend for smooth handling of text, audio, and visual data.

**Technologies:** Python, FastAPI, OpenAI API (Whisper), JavaScript, React.js, Node.js
